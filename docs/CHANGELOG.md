# BioData Agent 变更日志

本文件记录对外可见的产品、Web API 与 MCP 契约变化。详细技术说明见 README 与开发指南。

> **阅读导航（渐进披露，2026-08-01 起）**：本文件约 61KB 且按日期倒序增长，**不要整读**。先 `grep -n '^## ' docs/CHANGELOG.md` 列出版本条目，再按行区间只读目标日期条目。

## 2026-08-31 — 系统回复 LLM 化与下载统一浏览器通道（Web API 2.8.0 → 2.9.0）

- **系统回复统一为大模型最终答复**：检索回执在全站各入口（含继续对话）经 LLM 原位改写——概述执行过程与结果，
  并按需给出帮助、建议与提醒，替代此前的模板拼接句式；未配置大模型时如实回退到规则版回执。
- **下载统一走浏览器通道**：全应用唯一下载队列引擎（排队去重、追加、取消），数据文件、引文导出
  （RIS/BibTeX）与复用任务包一视同仁——全部经浏览器自身下载管理，可见、可管理、可取消；结果区保留下载面板，
  对话气泡内每批下载挂一颗「下载队列」pill，点击即开面板并滚动到对应队列。
- **修复**：检索与下载混合的一轮对话里，回复气泡现在同时挂检索结果 pill 与下载 pill；引文导出回执此前不挂
  pill、不进下载面板的问题；「你提到了下载——检索本身不包含这一步」指路条在下载动作真正执行成功后自动摘除，
  不再与已完成的下载并存。

### 契约

- 新增 `POST /api/search/reply`（additive）；网页端下载不再经服务端代下，既有 `/api/download/update` 队列语义
  不变；MCP 工具数与服务器版本不变（19 个，1.35.0）。

## 2026-08-30 — 在线 MCP 形态与逐条反馈操作条（Web API 2.7.0 → 2.8.0）

- **在线 MCP 形态**：同一 MCP 服务可随网页版以 streamable-HTTP 挂出（`/mcp`），Bearer 令牌鉴权——令牌只存
  sha256、仅创建时显示一次、可在帮助页随时吊销。在线形态为纯确定性服务（不消耗服务端 LLM 额度，LLM 参数
  推离安全档会被显式拒绝，隐式 LLM 路径自动降级为规则版）；「下载到本机」「本地资产核验」两个本机文件系统
  语义工具在线形态不提供（显式拒绝，错误码 online_tool_disabled）。本地 stdio 形态逐字节不变。
- **帮助页「接入 AI 助手」双方式**：方式一·在线接入（免安装）——生成在线接入令牌、复制配置片段即可接入
  支持 MCP 的 AI 助手；方式二·本地接入（功能最全）——复制接入提示词发给 AI 助手，由其完成本地形态接入。
- **逐条反馈操作条**：每条系统回复气泡下方提供 赞 / 倒赞 / 评论 / 分支——反馈不再局限于系统判定的高价值
  节点；分支会在新窗口基于该回复 fork 出平行会话。
- **前端体验**：首页输入框与其余输入框统一为同一样式与组件；识别到检索关键词时输入框给出视觉提示；发送
  消息与主界面/侧边栏内容交换改为连贯过渡动画；修复特定查询下系统回复偶发消失；修复输入框内按钮纵向居中。

### 契约

- 新增 `/mcp`（streamable-HTTP，Bearer 鉴权）；新增 `POST /api/account/mcp-token`（铸令牌）、
  `GET /api/account/mcp-tokens`（列表）、`POST /api/account/mcp-token/revoke`（吊销）；新增
  `GET /api/guide/agent-prompt`、`GET /api/guide/online-prompt`、`GET /api/guide/skill.zip`。

## 2026-08-14 — agent 多工具调用同批只读消费：查更新/看库容批量真并行（Web API 不变）

- 模型一轮发多个工具调用时，此前只采纳第一个、其余等下一轮带着新状态重判。经探针实测
  （互相独立的只读批量调用第 2 个起 schema/语义合法率 100%，n=371；而预发写库调用的
  参数保真仅 45%），现在 decide 一轮给出多个调用时：第 2 个及以后的**只读**调用
  （检查来源更新、读取数据库状态）逐个过既有全套校验后**同批执行**，省掉逐步重问的
  模型往返；写库操作（联网搜库、同步入库）与任何读不懂的调用出现即截断，仍回到
  「取第一个、下一轮重判」的老路，同批相同调用只执行一次。执行轨迹如实写明
  「一次给了 N 个、同批采纳 M 个、回炉再判 K 个」。
- 收益口径：每省一次重判约省一次模型往返（输入约 18k token，磁盘缓存命中约 17.8k）。

### 契约

- 无 HTTP/MCP/CLI 形状变化；agent 执行轨迹的措辞只增不改（additive）。生产提示词未动。

- MCP 服务器升为 `1.9.0`，工具数 5→7：新增 `browse_datasets`（全库浏览：所有来源并列的数据集 + 物种/平台/来源/年份分面 + 轻过滤 + 分页，对齐 Web `/api/datasets`）与 `get_dataset_introduction`（按 `uid`/`url`/`name` 返回单数据集确定性介绍，只整理现有元数据、不调用 LLM，对齐 Web `/api/introduction`）。
- `recommend_datasets` additive 增加四个 opt-in 参数：`facet_filters`（分面细化）、`suppressed_constraints`（忽略已命中→放宽）、`date_from`/`date_to`（发表时间范围），与 Web「数据细化 / 已命中 / 发表时间」一一对应；响应 additive 回显 `query_constraints`（含各维 `filter_id`）、`applied_facets`、`applied_suppressed`。

### 变更

- `facet_filters` / `suppressed_constraints` 的净化逻辑上移为 `workflow.sanitize_facet_filters` / `sanitize_suppressed`（Web + MCP 单一真源）；`webapp` 私有 `_sanitize_*` 改为薄委托，行为逐位不变。
- MCP 错误契约版本 `1.9.0`：`browse_datasets` 的 `limit`/`offset` 非法（非正/负/超上限 200）→ `bad_param`；`get_dataset_introduction` 未给键 → `empty_key`、查不到 → `not_found`。

### 边界

- 新增两个工具与四个参数**全程离线、确定性、只读**；默认不传时官方 767 冻结评测与旧调用逐位不变。**刻意不新增写/上传能力**：上传仍是带 same-origin + loopback 守卫的 Web 表单专有路径，MCP 保持只读不变量。
