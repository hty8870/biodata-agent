BioData Agent · 提交包（Windows / macOS / Linux 通用 · 命令行版）
================================================================

这个 zip 是全平台命令行版：解压后点一个入口脚本就全流程启动，前端在浏览器里用。
（Windows 另有一种图形化安装版 exe，装好后是独立的桌面窗口、不依赖浏览器；
如果你拿到的是这个 zip，用下面的方式启动即可。）

这个文件夹里有这些东西：

  1. 打开前端.bat                 Windows 双击启动
  2. 打开前端.command             macOS 双击启动
  3. 打开前端.sh                  Linux / 通用启动（终端里运行）
  4. biodata-agent\               程序本体与源码
  5. BioData Agent 使用说明书.pdf 全部功能的完整说明，建议先翻一遍


第一次启动
----------------------------------------------------------------
1. 确认已安装 Python 3.10 或更高版本。
   - Windows：         到 python.org 下载安装包（安装时勾选 Add to PATH）
   - Ubuntu / Debian：  sudo apt install python3 python3-venv
   - Fedora / RHEL：    sudo dnf install python3
   - macOS：            brew install python@3.12   （或到 python.org 下载安装包）
   也可以用系统自带或已装好的其它 Python 3.10+，启动器会自动找。

2. 启动（按你的系统三选一）：
   - Windows：双击「打开前端.bat」
   - macOS：双击「打开前端.command」
   - Linux / 通用：在终端里运行   sh 打开前端.sh
   若 macOS 提示“来自身份不明的开发者”，右键图标 → 打开；或先在终端执行 chmod +x 打开前端.command。

3. 首次启动会自动准备项目专用 Python 环境（约一两分钟）：只复用本项目的 .venv，
   没有就新建（只在需要新装依赖时联网），不会静默借用开发或 MCP 环境。
   如确需共用其它环境，须自行设置 BIODATA_PYTHON 明确指定。
   随后它会用英文问你三个可选问题，三个都可以直接按回车跳过：
     Configure an AI API key now? [y/N]              要不要现在配 AI 接口（跳过不影响使用）
     Install agent execution dependencies now? [y/N]  要不要装 AI 执行依赖（约 1 分钟）
     Download the local model now? [y/N]              要不要现在下本地语义模型（下载约 3 GB，装完占磁盘约 5 GB）
   答完就自动打开浏览器。这三项之后都能再补，详见说明书 2.2.3。

4. 页面地址默认是 http://127.0.0.1:7860 。
   如果 7860 已被占用，会自动改用 7861-7869 里第一个空闲的端口，
   实际地址以启动窗口里显示的那一行为准。
   如果同一版本已经在运行，会直接复用它而不重复启动；窗口里会写明
   复用的是哪一份安装，若和你想启动的不是同一份，会特别提醒。

5. 关闭启动时弹出的窗口（Windows 是黑色命令行窗口，macOS/Linux 是终端窗口），
   服务就停止了（或在终端里按 Ctrl+C）。


装好依赖之后，检索本身完全离线可用，不需要联网，也不需要任何密钥。
只有 AI 相关的可选功能（AI 重排、AI 润色说明、AI 中文导读）才需要联网。
「使用反馈」默认开启本地采集；每个本机账户首次发送前独立确认。只有部署方配置
安全 HTTPS 通道后才会脱敏自动上传，否则只存在本地、可手动导出；不采集 API Key、
密码和账户名。可在设置里关闭或清空当前账户尚未上传的记录；已上传数据不会因本地清空而远程删除。
